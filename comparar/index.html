¿Qué cambió entre una Constitución y otra?

Esta sección será el comparador visual del proyecto. Selecciona dos versiones para revisar diferencias artículo por artículo.

Constitución 2015

Versión anterior

El texto de esta versión se incorporará artículo por artículo desde las fuentes oficiales.

La comparación real mostrará cambios exactos de redacción, adiciones y eliminaciones.

Constitución 2024

Versión posterior

El texto de esta versión se incorporará a partir de la publicación oficial correspondiente.

Cada diferencia tendrá una referencia a la fuente y a la versión consultada.

Cómo funcionará

1. Elige dos años. 2. Selecciona un artículo. 3. Visualiza la redacción anterior y la nueva. 4. Consulta el contexto y la fuente.

Principio de transparencia

Texto oficial por un lado. Explicación por otro.

El comparador distinguirá visualmente el contenido constitucional de cualquier explicación educativa o contexto añadido por el proyecto. La fuente primaria será siempre identificable.
